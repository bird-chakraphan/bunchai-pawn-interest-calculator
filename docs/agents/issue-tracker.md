# Issue tracker
Use GitHub Issues in bird-chakraphan/bunchai-pawn-interest-calculator.
One parent issue represents one batch; use sub-issues for independently reviewable outcomes and a checklist for small steps.
Use the connected GitHub tools where sufficient. Do not infer that the invalid local gh token means GitHub access is unavailable.
Link batch scope, dependencies and evidence. Do not duplicate the full business specification in each issue.
Do not label a batch complete until technical verification, owner acceptance and integration are recorded.
